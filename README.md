# Alien Platformer  

**Alien Platformer** is a Unity 2D platformer game featuring classic platforming mechanics, enemies, collectibles, and polished gameplay with animations and sound effects.  

---

## 🎮 Features  
- Built with **Unity** as a **2D Platformer**  
- Smooth **Player Controller** for 2D movement  
- Collectible objects: **coins, health, hearts**  
- **Health Bar system** to track player’s health  
- Pick up **hearts** to restore health  
- Platforms that move between two positions  
- Sound effects for important events:  
  - Player death  
  - Projectile impact  
  - Enemy killed  
- **Player death system** (health reaches 0 → player dies)  
- **Dash move** for quick movement  
- **Projectile system** (shoot projectiles that travel)  
- **Enemy AI** that patrols and damages the player on collision  
- **Main Menu, Game Over Screen, and Win Screen**  
- Numerous **animations** with integrated sound effects  

---

## ⌨️ Controls  
- **Arrow Keys / A, D** → Move  
- **Space** → Jump  
- **Shift** → Dash  
- **F / Left Click** → Shoot Projectile  

---

## 🛠️ Installation  
1. Clone or download this repository.  
2. Open the project in **Unity**.  
3. Press **Play** to start the game.
